# Pop Strike · 漫画突击

[English](README.md) · 简体中文

根据参考视频实现的 Three.js 第一人称射击游戏：采用用户提供的 Nostalgos-12 色板，暖黄地面、珊瑚红与青绿掩体、蓝色钢架、淡紫色点缀、炭黑描边和深色圆头火柴人。

英文名为 **Pop Strike**，中文副标题为「漫画突击」，宣传语为「Make it pop.」。首页、浏览器标题、场景标牌和启动提示已统一名称。单人敌人统一称为「突击队员 / STRIKER」，冲锋枪称为「疾风冲锋枪」，普通击倒提示为「POP!」，招募海报使用「POP SQUAD」。根目录的启动命令继续可用，之前保存的玩家呼号和最高分也会继续读取。

## 英文版与 itch.io 发布

在项目根目录运行 `python3 scripts/build_release.py`（或 `npm run build:release`），会生成两个完整英文版本，保留当前中文版：

- `dist/pop-strike-itch-en.zip`（itch.io 网页包）：单人生存；ZIP 根目录包含 `index.html`，所有资源和字体均随包提供，局域网入口已禁用。
- `dist/pop-strike-lan-en.zip`（局域网下载包）：单人和红蓝对战；包含英文界面、房主服务、说明书及 macOS / Linux / Windows 启动脚本。

本机预览英文网页版：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist/pop-strike-itch-en
```

打开 `http://localhost:8000/index.html`。英文联机版解压后执行其中的 `bash start-lan.sh`；如果中文房主正在占用 5173，可用 `env PORT=5174 bash start-lan.sh` 单独启动英文房间。

上传设置与可直接使用的英文介绍见 [itch.io 发布指南](docs/itch-io.md)。[英文首页预览](docs/images/lobby.png) · [英文战场](docs/images/gameplay.png)。发布包由本地构建生成，不随源码提交。

翻译表在 `scripts/release/en.json`，英文布局调整在 `scripts/release/en.css`。打包时会检查遗漏的中文、依赖路径和 itch.io 文件大小限制；`dist/` 是生成结果，修改游戏后重新打包即可，不要直接修改其中的游戏文件。

上传 GitHub 源码时，包含 `pop-strike/`、`docs/`、`scripts/`、中英文 README、根目录 `package.json`、`start-lan.sh` 和 `.gitignore`。README 使用的展示图统一放在 `docs/images/`。历史开发截图已归档到本地 `dist/archive/screenshots/`，不参与运行或源码上传；`dist/` 中的发布包和录屏也无需提交。

标题与大号数字使用 [Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone)，中文界面使用[站酷快乐体](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile)，较长说明保留易读的系统中文字体。字体与 SIL Open Font License 均打包在 `pop-strike/fonts/`，局域网玩家无需访问外部字体服务。[查看卡通字体首页](docs/images/lobby.png)。

单人模式的突击队员出生时会随机戴上金黄、珊瑚红、亮蓝、青绿、淡紫或米白头带，侧后方带结与两条加长飘带使用同色，从正面也能看到伸出头部轮廓的带尾；颜色随角色保持到倒地，不会在移动或受击时变色。飘带会随跑动、转身分段弯曲，两条带尾错开摆动；停步后有短暂惯性，待机时只轻微摆动。倒地时飘带逐渐停止并向地面放平，保持与带结相连。头带为装饰，不改变爆头判定。局域网角色继续按红蓝队色佩戴头带。

当前 12 色 PNG 保存在 `pop-strike/assets/nostalgos-12.png`，原始色值、建筑色系与队伍颜色集中在 `pop-strike/palette.js`；界面、枪械、标牌和特效也采用这组颜色。光照、透明度和漫画阴影会产生相应明暗变化。上一版 LUAP-40 色板仍保留供比较。本次配色更新只需刷新各玩家页面，无需重启服务。[Nostalgos-12 首页](docs/images/lobby.png) · [Nostalgos-12 战场](docs/images/gameplay.png)。

## 启动与局域网联机

无需安装 npm 依赖。在项目根目录运行：

```bash
bash start-lan.sh
```

启动脚本优先使用 Node.js 18 或以上；这台电脑没有 `node` / `npm` 时，会自动使用已安装的 VS Code 自带运行时。在 fish 中也可以直接执行这条命令。其他电脑作为玩家只需要浏览器，不需要安装 Node.js 或复制项目。

1. 房主保持终端运行，在浏览器打开 `http://localhost:5173`。
2. 终端会打印「同一局域网的朋友打开」地址，例如 `http://192.168.1.23:5173`。朋友连接同一 Wi-Fi / 局域网，在浏览器打开这个地址。
3. 每个人点击「局域网对战」，输入呼号并加入。房间面板也会列出房主地址；有多张网卡时，选择与朋友同一网段的地址。
4. 加入时自动平衡红蓝分队，最多 8 人。只有一人时可以探索和练枪，第二人加入后自动开始计分。

红蓝双方按**队伍总击倒数**计分：全队先得 20 次击倒，或在 5 分钟结束时得分较高的一队获胜；同分为平局。结算展示 10 秒后自动开始下一局。阵亡 3 秒后自动重生，重生保护持续 2 秒，开火会解除保护。队友不受友军伤害。正上方集中显示回合时间、红蓝队击倒比分及自己的击倒 / 阵亡。右上角实时显示「击杀者 → 武器 → 被击杀者」，爆头附有标记；按住 Tab 或展开左侧「战绩」可查看全员数据。角色佩戴珊瑚红或亮蓝头巾，后脑带结和短飘带，头顶呼号也使用队伍颜色。联机小地图仅显示自己和存活队友，不显示敌方位置；自己的方向标记为暖黄。

移动、碰撞、楼梯、爬梯、攀箱、命中、射速、弹药及重生统一由房主服务计算，客户端平滑显示位置。保留原来的单人生存模式，首页「开始战斗」仍进入单人游戏。联机时 Esc 释放鼠标并打开菜单，房间里的战斗继续；点击「离开房间」回到首页。房主关闭服务后，其他玩家会收到断线提示，可以在服务恢复后重新加入。

被击倒后，镜头会后退并俯视自己的倒地角色，场景转为黑白，HUD 保留颜色。倒地时会结合受击方向，随机变化身体偏转、手脚落点、抬起幅度和关节摆动时机；动作从当前姿势开始，关节长度保持不变，落地后停止抽动。联机按玩家及本次生命生成固定的姿势种子，远端角色也按真实受击方向倒下。死亡卡片显示击杀者、武器、爆头信息和服务端同步的「3 → 2 → 1 秒后复活」；重生时恢复彩色和第一人称视角。回合结束时，卡片改为显示胜方和下一局倒计时。镜头会避开墙壁、天花板及楼层，死亡期间不能移动、射击或开镜。单人生存模式也使用倒地画面，训练结束后点击「再来一局」重新开始。[查看联机死亡画面](docs/images/lan-respawn.png)。

更新后请重启房主服务并刷新各玩家页面，以加载死亡信息和新版 HUD。

安装了 Node.js 的电脑也可以运行：

```bash
npm run dev
# 或无需 npm：
node pop-strike/server.mjs
```

默认监听所有网卡的 5173 端口。按 `Ctrl+C` 停止服务。换端口可运行 `env PORT=5174 bash start-lan.sh`（bash / fish 通用）。如果朋友无法访问，确认使用的是房主的局域网 IP，而非朋友电脑的 `localhost`；在房主防火墙中允许 TCP 5173，并确认 Wi-Fi 没有开启访客网络 / 客户端隔离。

只玩单人模式时仍可使用静态服务器：

```bash
python3 -m http.server 5173 --bind 127.0.0.1 --directory pop-strike
```

Python 静态服务不提供联机功能。切换到联机服务前，先停止占用同一端口的静态服务。

触屏设备提供移动摇杆和射击、瞄准、换弹、换枪、跳跃按钮，拖动场景转向。靠近梯子时会出现「爬梯」按钮，抓住后前后推摇杆上下攀爬，点击跳跃可跳离。

游戏全屏时仅保留场景、战斗 HUD 和游戏内菜单，隐藏外部「训练场」「作战指南」导航及底部操作提示；画布和狙击镜会适配屏幕尺寸。[查看全屏战场](docs/images/overview.png)。

箱子、沙袋、桶和平台顶部可以站立，走出边缘会受重力下落。中央瞭望塔正面有楼梯，背面的黄色梯子也可以攀爬，两条路线都通向上层环形平台。攀箱需要箱沿在可够到的高度，并留有足够的落脚和头顶空间。

塔楼楼梯扶手采用连续的阶梯形栏板，立柱顶面略高于栏板，消除接缝内部面和不同颜色顶面的共面闪烁。

右侧金黄色兵营、左侧珊瑚红军械库和后方工坊均可进入，每栋都有正门及侧门。兵营与军械库现在都有可进入的二层房间、外楼梯和阳台。室内设有床铺、储物柜、工作台或物资箱，并保留通畅的行走路线。门窗是真实开口，可以向内外射击；实体墙、家具和屋顶会阻挡子弹，墙壁与屋顶也保留玩家碰撞。

上层路线为「军械库外楼梯 → 二楼阳台 → 后方带顶棚回廊 → 兵营二楼 → 外楼梯回到地面」，可双向通行。回廊另有台阶通往较低的工坊屋顶，原有瞭望塔与梯子也保留。上层增加了掩体和巡逻敌人，地面可以从回廊下穿行。雷达会随玩家高度切换楼层显示，朝上／下的三角标记表示位于不同高度的角色：单人模式显示敌人，联机模式仅显示队友。

地面现在是一组错开的货运区：西侧、东北侧和南侧有双层集装箱，单箱高 2.8 米、双层高 5.6 米，遮挡地面和部分回廊射线。东侧浅黄色集装箱两端敞开，可以穿行、射击，也可以从外梯登上箱顶。西侧可以沿三级货盘攀到低层箱顶，再用黄色梯子爬到上层。南侧还有叉车与高货物，东侧有三层管材架，西北侧有发电机组；其间保留中路、两翼绕行以及原有建筑出入口。

新货场与二楼使用相同的碰撞和子弹射线，单人、联机均生效。修改地图后请重启 `bash start-lan.sh`（或 `npm run dev`）并刷新各玩家页面，使房主和客户端加载同一版场景。

建筑与货场以 Nostalgos-12 的暖黄、珊瑚红、青绿为主要色块，搭配蓝色钢架与少量紫色掩体，浅色墙面和深色收边保持层次。当前地图截图：[货场全景](docs/images/overview.png) · [地面视角](docs/images/gameplay.png)。

## 玩法与反馈

单人生存模式为 3 分钟、3 波敌人。火柴人会冲刺接近、横移换位、停步举枪再射击，移动和掩体可以降低受击概率。普通击倒 100 分，爆头 150 分，连续击倒获得额外分数。每次击倒恢复 7 点生命，完成一波恢复 20 点。最高分保存在浏览器本地。

六种武器均支持单人和局域网对战，弹匣独立记录。备用弹药无限，界面的「∞」表示无限备弹；弹匣未满时按 R 换弹，空弹匣继续开火会自动换弹。换枪会取消正在进行的换弹，保留原弹量；切回狙击枪不能跳过拉栓冷却。

| 按键 | 武器 | 主色 | 弹容量 | 射击方式 | 换弹时间 |
| --- | --- | --- | --- | --- | --- |
| 1 | 突击步枪 | 蓝色 | 30 | 自动连射 | 1.35 秒 |
| 2 | SHOTGUN 泵动霰弹枪 | 金黄 | 6 | 单次点击，9 颗散弹 | 1.8 秒 |
| 3 | SMG 冲锋枪 | 珊瑚红 | 30 | 自动连射，射速更快 | 1.15 秒 |
| 4 | SNIPER 栓动狙击枪 | 青绿 | 5 | 单次点击，拉栓间隔 1.15 秒 | 2.4 秒 |
| 5 | HAND CANNON 重型手枪 | 淡紫 | 7 | 半自动 | 1.65 秒 |
| 6 | REVOLVER 左轮 | 米白 | 6 | 单次点击 | 2.05 秒 |

狙击枪有实体瞄准镜；按住右键进入圆形放大视野，外围为深色遮罩，镜内使用细十字线，并降低转向灵敏度。开镜时隐藏枪身；换弹、换枪、暂停、阵亡和回合结束都会退出瞄准。触屏点击「瞄准」切换开镜状态。[查看瞄准镜效果](docs/images/sniper-scope.jpg)。狙击枪身体伤害 85、爆头 170；霰弹枪和冲锋枪有距离衰减，单人和联机使用相同的散布、射程及伤害配置。

各枪有独立主色，第一人称和远端枪模使用同一配色，HUD 顶部色条随武器切换。各枪有独立模型、HUD 图标、枪声与后坐力，并包含弹匣拆装、霰弹枪泵动、手枪套筒、狙击枪拉栓及左轮弹巢动画。联机远端角色同步所选枪型，双手跟随握把、护木与换弹动作。保留弹壳、曳光弹、漫画弹痕、命中闪白、爆头与连击提示，音效通过 Web Audio 实时合成。

突击步枪使用长护木、方框瞄具与实心枪托；冲锋枪使用短圆筒式机匣、短枪管、圆环瞄具、细长弹匣及镂空枪托，整体长度约为步枪的 65%。冲锋枪采用 Nostalgos-12 的珊瑚红，与步枪的蓝色区分；第一人称、联机角色和 HUD 图标同步外形。

第一人称使用黑色的圆润手掌、手腕和略带收细的前臂，与各色枪身、弹匣区分。右手握住握把，左手托住护木或辅助握持手枪；换弹时将枪抬入视野，左手握住弹匣下半部，手腕持续连接前臂。

更新武器后，房主需重启 `bash start-lan.sh`，所有玩家刷新页面。联机协议已升级，旧页面会提示刷新，避免新旧武器表混用。


## 文件

- `start-lan.sh`：支持本机 Node.js / VS Code 运行时的启动入口。
- `pop-strike/server.mjs`：网页服务、局域网地址、WebSocket 连接与 60 Hz 服务端循环。
- `pop-strike/room.mjs`：红蓝分队、队伍比分、权威物理 / 命中 / 弹药 / 重生，20 Hz 状态广播。
- `pop-strike/websocket.mjs`：无外部依赖的 WebSocket 文本传输、心跳与消息长度限制。
- `pop-strike/multiplayer.js`：联机客户端、远端角色、呼号和移动动画。
- `pop-strike/weapons.js`：六种武器共用配置、角度散布和距离伤害。
- `pop-strike/weapon-models.js`：第一人称与远端角色共用枪模、持枪锚点和机械动画。
- `pop-strike/game.js`：玩家、敌人、单人波次、联机入口、HUD 和反馈。
- `pop-strike/death-view.js`：本地玩家倒地、镜头拉退、掩体避让和重生清理。
- `pop-strike/enemy.js`：火柴人模型、髋膝踝步态、双手持枪、受击和倒地动画。
- `pop-strike/world.js`：程序化场景、颜色批处理、碰撞和出生点。
- `pop-strike/palette.js`：Nostalgos-12 原始色值、建筑色系与红蓝队颜色。
- `pop-strike/upper-yard.js`：二层房屋、外楼梯、回廊、屋顶平台和上层出生点。
- `pop-strike/cargo-yard.js`：堆叠集装箱、穿行通道、箱顶攀爬、叉车、管材架和发电设备。
- `pop-strike/navigation.js`：敌人按所在高度检查墙体和平台边缘。
- `pop-strike/physics.js`：玩家完整身体碰撞、重力、落地、台阶、攀箱和梯子控制。
- `pop-strike/audio.js`：分层枪声与战斗音效。
- `pop-strike/style.css`：漫画风格界面及响应式布局。
- `pop-strike/vendor/`：本地 Three.js r180（MIT 许可证）。
- `pop-strike/fonts/`：本地 Lilita One、站酷快乐体与 Barlow 字体，以及各自的 SIL Open Font License。

所有运行资源均位于项目内，HTTP 服务启动后可离线使用。单人模式可以部署到静态网站服务器；联机需要运行 `server.mjs`。需要支持 WebGL 2 的浏览器。

```bash
npm run check
```
